# Presentation Run-Through Timer

Add slide sections with time budgets, run a live countdown per section, and review actual vs. planned time after the run-through.

## Features
- Add/remove sections with a name and allocated minutes
- Live countdown with color-coded progress bar (green → yellow at 80% → red at 100%)
- Auto-advances to the next section (or shows overtime) when time runs out
- Post-run review showing each section's actual vs. planned time with over/under indicators
- Keyboard shortcuts: Space = pause/resume, N = advance to next section

## Usage
Set up sections in the setup panel with names and time budgets. Click "Start Run-Through" to begin. The active section shows a countdown and progress bar. Use the Pause/Resume and Next buttons (or keyboard shortcuts) to control the run. When finished or stopped, a review table shows how your actual timing compared to the plan.
